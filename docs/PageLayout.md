# PageLayout.md - 페이지별 레이아웃 정의

사내 템플릿이 없으므로 일관된 전문 보고서 스타일(16:9, 진한 블루/그레이 톤, 깔끔한 타이포)을 기준으로 정의.
모든 페이지: 상단 제목 영역, 하단 페이지 번호, 여백 충분, 오버플로우 방지.

## 공통 레이아웃 원칙
- 제목: 상단 0.5~1.0" , 큰 폰트 (28~36pt), 볼드, 결론형 문장
- 본문: 좌측 정렬 또는 카드형, 본문 18~22pt
- 데이터: 차트/테이블은 네이티브 객체, 충분한 공간
- 색상: 주조 #003366 (다크 블루), 강조 #0066CC, 배경 화이트/라이트 그레이
- 로고: 필요 시 우측 상단 작은 위치 (템플릿 없으므로 선택)

## 페이지별 레이아웃

### 페이지 1 (표지)
- 전체 배경 단색 또는 미묘한 그라데이션
- 중앙 정렬 큰 제목 (40pt+)
- 부제 하단
- 하단 연도·작성 정보

### 페이지 2~3 (배경·질문)
- 좌측 텍스트 블록 (60%)
- 우측 간단한 아이콘 또는 타임라인/질문 박스
- 제목 상단 전체 폭

### 페이지 4~6 (데이터 중심)
- 상단 제목
- 중앙 대형 차트 (바 차트 또는 테이블, 네이티브)
- 하단 또는 측면 짧은 인사이트 텍스트 2~3줄
- 차트 범례 명확

### 페이지 7 (전략)
- 좌측 설명 텍스트
- 우측 공장 위치 리스트 또는 간단한 맵 스타일 아이콘 배치
- 또는 3~4개 카드 레이아웃

### 페이지 8~9 (분석)
- 4개 또는 2x2 카드 레이아웃 (강점/약점)
- 각 카드: 아이콘 + 짧은 제목 + 설명
- 또는 좌우 비교 레이아웃 (강점 | 약점)

### 페이지 10 (결론)
- 상단 큰 결론 제목
- 중앙 핵심 메시지 강조 박스
- 하단 2개 과제 (전기차 / 브랜드) 아이콘 카드
- 여백 넉넉히, 임팩트 있게

## 시각 QA 포인트
- 텍스트 오버플로우 없음
- 요소 간 간격 ≥0.3"
- 대비 충분 (다크 텍스트 on 라이트 배경)
- 차트 라벨 가독성
- 일관된 여백과 정렬
