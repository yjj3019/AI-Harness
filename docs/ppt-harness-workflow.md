# Claude Code를 활용한 오피스 문서(PPT) 제작 하네스 워크플로

단일 프롬프트로 전체 PPT를 생성하면 퀄리티 저하와 무한 수정 사이클에 빠지기 쉽습니다. 
이 문서는 **문서화 중심 단계별 접근**을 통해 오피스 문서 제작을 안전하고 검증 가능하게 수행하는 하네스 방법을 정리합니다.

기존 AI-Harness의 Phase 관리, 샘플 우선 검증, 독립 평가자, compound-log 원칙과 통합하여 구성했습니다.

## 1. 단계별 접근의 필요성

- **One-Shot 제작의 문제**: 한 번에 전체 슬라이드를 생성하면 레이아웃 일관성 부족, 데이터-메시지 불일치, 브랜드 톤 위반 등이 발생하고 수정 비용이 크게 늘어납니다.
- **해결**: 문서 기반 단계별 구성 → 샘플 검증 → 전체 생성으로 분할.
- **적용 사례**: "2010년 한국 자동차(현대·기아차) 글로벌 시장 경쟁력 분석 보고서(10장)" 등 업무용 보고서, 제안서, 교육 자료.

## 2. 프로젝트 기본 설정 (CLAUDE.md)

`CLAUDE.md`는 프로젝트의 ‘헌법’ 역할을 합니다. 매번 프롬프트로 반복 설명할 필요 없이 최상위 지침을 제공합니다.

### 필수 항목 (예시)

```markdown
# CLAUDE.md - PPT 제작 하네스

## 핵심 규칙
- 샘플 우선: 전체 생성 전 항상 3장 샘플을 먼저 생성·검증한다.
- 브랜드 준수: 지정된 템플릿과 톤앤매너를 엄격히 따른다.
- 단계별 진행: One-Shot 금지. Brain → UpgradeBrain → Phase → PageDetail → PageLayout 순서를 준수.
- 객관적 검증: 샘플 확인 후에만 전체 분량 생성을 허용한다.

## 참조 문서 및 스킬
- Anthropic 공식 pptx 스킬 (skills/pptx)
- 사내 PPT 템플릿: `templates/회사_PPT_템플릿.pptx`
- 상세 워크플로: docs/ppt-harness-workflow.md
- 단계 체크리스트: docs/PHASES.md
```

### 스킬 및 템플릿 연결
- Anthropic 공식 **pptx 스킬**과 사내 템플릿을 프로젝트 루트에 배치.
- CLAUDE.md에 명시적으로 연결하여 Claude가 일관된 톤·레이아웃·브랜드 가이드를 인식하도록 한다.

## 3. 단계별 문서 구조화 프로세스

아이디어를 논리적으로 구체화한 뒤 시각적 레이아웃까지 정의합니다.

| 문서 | 역할 | 출력 예시 |
|------|------|----------|
| **CLAUDE.md** | 최상위 헌법 및 목차. 스킬·템플릿 연결 | 규칙, 참조 링크 |
| **Brain.md** | 머릿속 아이디어 자유 메모 | 불렛 키워드, 사례, 질문 |
| **UpgradeBrain.md** | Q&A를 통해 논리적 구체화 | 정리된 주장, 근거, 구조 |
| **Phase.md** | 기승전결 흐름 구성 | 기(문제)→승(현황)→전(전환)→결(결론) |
| **PageDetail.md** | 페이지별 핵심 메시지, 데이터, 도표 | 슬라이드별 내용 스펙 |
| **PageLayout.md** | 시각적 배치 정의 | 제목/텍스트/이미지/그래프 위치 |

### 권장 순서
1. Brain.md에 자유 생각
2. UpgradeBrain.md에서 질문-답변으로 구체화
3. Phase.md로 전체 스토리 흐름 확정
4. PageDetail.md에 페이지별 내용 정의
5. PageLayout.md로 시각 레이아웃 확정
6. 샘플 3장 생성 → 검증 → 수정
7. 전체 PPT 생성

## 4. 샘플 제작 및 검증 (수정 비용 최소화)

전체 문서를 한 번에 만들면 방향이 맞지 않을 때 수정 비용이 큰 넓니다. 반드시 샘플을 먼저 만듭니다.

### 프롬프트 예시

```
/pptx CLAUDE.md 파일의 내용을 바탕으로 샘플 결과물 3장 우선 만들어줘. 
샘플 파일 이름은 sample.ppt로 만들어줘.
```

### 검증 포인트
- 톤앤매너 일관성
- 핵심 메시지 명확성
- 데이터 시각화 적합성
- 브랜드 가이드 준수 여부

맞을 때까지 샘플을 수정한 후 전체 제작으로 진행합니다.

## 5. 전체 PPT 완성

샘플 검증이 끝나면 CLAUDE.md + sample.ppt를 바탕으로 전체 분량을 생성합니다.

### 프롬프트 예시

```
지금까지 만든 CLAUDE.md와 sample.ppt 내용을 바탕으로 전체 PPT 10장 작성해줘.
```

## 6. 하네스 원칙과의 연계

| 하네스 원칙 | PPT 워크플로 적용 |
|---------------|-----------------|
| No One-Shot | 샘플 → 전체 분할 |
| Phase 관리 | Brain → Phase → PageDetail → PageLayout |
| 독립 평가 | 샘플 검증 후 전체 생성 허용 |
| Compound Log | 수정 패턴·실패 사례를 로그하여 다음 제작에 반영 |
| Context Reset | 긴 작업 시 HANDOFF.md로 상태 이관 |
