## 내용 게이트

- **근거 없는 수치·기능 0건**: F3(설계 세부)·F4(지원 범위) = 공식 문서 403 → 전 산출물에 '미검증(재실측 필요)' 라벨. 확인 주장 = F1·F2 2건(공식 페이지 HTTP 200).
- **신뢰 라벨**: 확인/미검증/제안 3단계 구분(§15 반영 기준).
- **의사결정 프레임**: XLSX 축·가중치는 제안(가설) — 측정값이 아님(표기됨).
- **변환 의미 불변**: 8종이 01-facts.md 동일 근거표 공유.

- **배경**: 사용자 평가 1회차 "10/100" → v2(디자인 시스템 + 콘텐츠 보강) → 2회차 "약 50/100, 좀 더 노력해 달라" → v3.
- **v2 (2026-11-11)**: 네이비 #0B1F3A + 상태 팔레트(확인=그린/미검증=레드/제안=앰버) · 슬라이드 크롬 · 상태 칩 · 카드·테이블 레이아웃, 일반 배경 지식·채점 예시·XLSX 3시트 추가. 시각 검증 결함 2건(출처 열 겹침 · 규칙 카드 잘림) → 수정·PASS.
- **v3 (2026-11-12)**: ① **나래이션 구조** — 질문(결정 프레임·가설 시나리오) → 근거 → 개념 다이어그램 → 배경·트레이드오프 → 결정 → 채점 → 프로세스 → 게이트 → 한계 → 다음 단계 → 출처 ② **실제 다이어그램** — VM/컨테이너 레인(아이콘) → 한 플랫폼(확인 F1) → 공통 운영(제안 F5) + 근거 주석(확인/미검증 도트) ③ **아이콘·가호 타이포그래피** — VM 스택/컨테이너/상태 글리프 칩, 섹션 가호 번호 ④ **트레이드오프 콘텐츠** — VM vs 컨테이너 4차원 비교(전부 '일반 지식, 제품 사양 아님' 라벨) ⑤ DOCX 네이비 커버 블록 + 트레이드오프 표, SVG v3 다이어그램. 시각 검증 결함 3건(표지 칩 패널 침범 · S2 항목 가림 · S5 아이콘-본문 겹침) → 수정 후 재렌더·재실독 PASS.
