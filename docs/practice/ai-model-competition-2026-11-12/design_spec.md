### 2.2 타이포 스케일 (D4 해결 — reveal.js 디스플레이 스케일 흡수)

- INK `101418` · PAPER `FFFFFF` · LINE `D8DDE4` · MUT `8A93A3` · SUB `46505E` — 유지

### 2.4 구조 도형 규칙 (D2 해결 — slidev 다이어그램 철학: 텍스트→도형)

- 티어 = 수직 스택 막대 (폭 감소 11.5→9.5in, 높이 0.34in, 간격 0.12in)
- 가격 = 수평 막대 (로그 스케일, x=0.5→12.9in 영역, 축 라벨 "백만 토큰(MTok)당 · 로그 스케일")
- 벤치마크 = 값 0~100에 비례한 인라인 막대 (행 높이 0.42in, 막대 0.14in)
- 매핑 = ①~④ 번호 + ↔ (glyph, Consolas)
- 모든 도형은 **직사각형+텍스트** (python-pptx shape, 이미지/차트 API 0 — 결정론 유지)
