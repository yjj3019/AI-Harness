# OpenShift 클러스터 RHEL 9.4 업그레이드 검토 노트

## 개요

OpenShift 4.17 클러스터의 노드 운영체계를 RHEL 9.4로 올리는 방안의 검토 결과를 정리한다. 목표는 클러스터 안정성 향상이다.

## 현황

클러스터에는 노드 14개, namespace 3개, pod 42개가 실행 중이고, OLM이 관리하는 operator는 8개다. CVE-2026-12345 패치가 RHEL 9.4에 포함되어, 해당 CVE에 노출된 노드는 업그레이드 대상이다.

## 제약 사항

유지보수 창은 약 7일. 추정치이며, 워크로드 부하에 따라 달라질 수 있고, 아직 검증하지 않은 수치다.

## 리스크

- 노드 드레인 중 pod 재스케줄링 실패 가능성
- 업그레이드 중 CVO(Cluster Version Operator)가 일시적으로 대기 상태(waiting)로 전환될 수 있음
- 네트워크 어댑터 드라이버 호환성 미확인

## 결론

업그레이드로 보안 취약점을 해소하고 장기적인 운영 안정성을 확보할 수 있다. 다만, 리스크 3건에 대한 추가 검증이 필요하다.
