## Remediation investigation and development trials

The original three-host prompts ran outside this repository without its project instructions, so the original D05 response is not evidence that the repository's actual rules were loaded and failed. `docs/PHASES.md` already prohibits automatic resend before reconciliation, and ToolBroker's UNKNOWN behavior is separately covered by fixture tests. We trialed a concise shared outcome rule as a synthetic prompt prefix, not as proof of host instruction discovery. The rule was revised twice after observing results and was ultimately removed from AGENTS.md and CLAUDE.md because development cases still exposed unwanted assumptions.

First candidate: 18 calls (three hosts, three cases, twice each) completed. The previously weak Grok D03 and D06 examples explicitly reported failure and missing current-tree evidence in both repetitions, and both Claude D05 repetitions stopped resend pending reconciliation.
