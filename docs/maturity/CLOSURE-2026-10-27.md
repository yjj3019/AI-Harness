## Repository changes under validation

- Test summary parsing: isolate complete summary blocks, reject any failed/incomplete mixed-format result, require exact accounting including TODO and safe integer counters. Pytest warnings are diagnostics, xfailed counts as skipped, and xpassed conservatively fails the gate.
- Attestation replay: recheck the source tree after successful execution before claiming verification.
- Destructive-command guard: scope rm/chmod checks to literal simple commands; handle quotes/delimiters and protected root descendants. This remains a lexical guard, not a shell interpreter or sandbox.
- ToolBroker: malformed/truncated/non-finite provider outcomes become durable UNKNOWN; never automatically resend uncertain work. Incoming connections have finite socket read timeouts and bounded worker admission.
- Windows recovery: exercise actual forceful process termination, FAIL evidence and explicit manual recovery rather than skip the whole scenario. This is not POSIX signal certification.
- CI actions: upgrade checkout/setup-node/setup-python to current v7 major releases to remove deprecated action-runtime warnings. Node application test matrix remains 22/24.
