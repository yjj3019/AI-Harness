# Routing Examples

- "로그인 폼에 XSS 방지 추가하고 테스트도 작성해줘" → coding-master (primary) + security-master
- "이 에러 왜 나는지 찾아줘" → debugging-master
- "대시보드 화면 디자인해줘" → design-master
- "이 기능에 로그랑 메트릭 넣어줘" → observability-master
- "이 외부 스킬 설치해도 돼?" → skill-audit
- "기능 하나 처음부터 끝까지" → skill-composition then coding-master
