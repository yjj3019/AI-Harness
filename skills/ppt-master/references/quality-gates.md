# Quality Gates (before claiming done)

Run these checks. Record results. Any FAIL must be fixed or explicitly accepted.

## Visual

- No overflow or clipped text
- Sufficient contrast (especially small text)
- Consistent alignment and spacing
- Clear visual hierarchy
- No overlapping elements that obscure meaning

## Editability

- Text is native text boxes (not images of text)
- Charts/tables are native where claimed
- Shapes have working adjustment handles where relevant
- File opens cleanly in PowerPoint

## Chart honesty

- Visual encoding matches the claim in the title or annotation
- Axes, units, and sources are clear
- No truncated axes that distort the message without disclosure

## Completeness

- Every planned slide is present
- Action titles form a coherent ghost deck
- Speaker notes exist if the brief required them

## Evidence

- Prefer rendered pages (PDF/PNG) or file inspection over assertion.
- Pair with [design evidence checklist](../../design-evidence-harness/SKILL.md).
- Inside a Phase, record results only through the phase gate.
