# Card Examples

**Good card**
- Done: tests written and failing for the new endpoint
- Blocked: need confirmation to add a migration
- Question: Apply migration now? (yes / no / later)
- After answer: if yes, run migration and re-test; if no, stop and note the decision

**Avoid**
- Asking again while a card is already open
- Starting a fresh session that re-implements completed steps
- Vague “what should I do?” without listing completed work
