# 미적 감각 평가표 (자체 작성 — 7축 100점; 사용자 제공 조사(외부, 2026-11-11)의 제안 축에 구체 체크로 재구성, 원문 미복사)

각 축은 **이 저장소 스킬용 자체 기준**이며 특정 저장소의 공식 점수 체계가 아니다. 점수 = 이 표의 체크로만 얻는 수치이고, 렌더링 실측·무결점이 아니다.

**채점 규칙**: 각 축은 **자기 배점 만점 안에서 해당 축 체크를 충족한 비율로 배점**한다(예: 구도·균형 20점 = 해당 4개 체크 각 5점; 타이포 등 15점 축 = 체크당 3.75점). 관찰 불가한 체크는 점수에 넣지 않고 **미검수**로 보고한다. 합계 100점.

| 축 (배점) | 배점 체크 | 0점 확정 실패 |
| --- | --- | --- |
| **구도·균형 (20)** | 중심·제3 지점/여백 배분, 한 지점으로 시선, 겹침 없음, 그리드/리듬 일관 | 요소 겹침/화면 밖 → 0 |
| **타이포·위계 (15)** | 서체 2~3종, 대비 위계, 크기·굵기 역할 고정, 주 1줄 | 본문=제목, 크기 균일 → 0 |
| **색채·조화 (15)** | 팔레트 3~4색, 대비 충분, 회색조/색맹 정상 | 색만으로 구분·대비 부족 → 0 |
| **여백·비례 (15)** | 여백 확보, 숫자/여백 비례, 밀도, 축 겹침/축 절단 없음 | 축 절단/면적 왜곡 → 0 |
| **독창성·주제 (15)** | 주제에 붙은 선택, 기본 팔레트/서체 아닌 선택, 1 개별 아이디어 | 주제 무관 반복 → 0 |
| **가독성·전달 (15)** | 문장 1, 레이블이 문장, 단위·출처 명시, 빈/오류/로딩 상태 | 단위 없음 · 출처 없음 → 0 |
| **렌더링 (5)** | 완료 크기 렌더링 실측, 줌아웃 검사 | 렌더 겹침/잘림 → 0 |

## 통과 기준

- **PASS = 합계 ≥ 70/100 이고, 4블록 4종 모두 제출, 렌더링(5) 축 실측 포함. 0점 확정 실패 축이 1개라도 있으면 합산과 무관하게 FAIL.** 점수표 없음·렌더 미실측 → **판정 불가(FAIL)**.
- 70 미만 → 1회 수정 → 재채점(최대 2회) → 남은 위험을 '미검수'에 명시.

**산출 4블록**: **점수표 / 유지(보존 사실) / 근거(출처·데이터) / 미검수** — 한 블록이라도 비어 있으면 판정 불가.

**재채점**: 신선한 시선 1회 → 점수 → 70 미만 → 1회 수정 → 재채점(최대 2회) → 남은 위험 명시.
