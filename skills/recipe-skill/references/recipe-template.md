# Recipe Template

```
examples/recipes/<name>/
  SKILL.md          # done criteria + verification
  rules.example.json # trigger snippet
  README.md         # permissions rationale + how to enable
```

## SKILL.md minimum

- What “done” means
- How to verify
- What to do if blocked (card or ask)
- What not to do (e.g. do not push, do not delete)

## README minimum

- Why this access is needed
- How to install the skill and merge the rule
- What remains local vs. what is sent out
