# 형식별 품질 게이트 (자체 작성 — 파일이 '열린다'는 것은 품질 검증이 아니다; [SKILL.md](SKILL.md)의 게이트 기준)

## 공통 (모든 형식)

- [ ] 파일 열림·구조 검사(패키지/관계/압축 유효)
- [ ] 사실 목록(facts) + 출처 — 숫자·날짜·통계 전부 출처 있음, 없으면 삭제
- [ ] 이모지 0 · PII 0 · 불안전 링크 0
- [ ] 색 선언 시 대비(WCAG AA) — 렌더링/도구 미보유 시 `unavailable` 명시
- [ ] 렌더링(가능할 때): 실제 뷰어 출력 확인 — 겹침·잘림·누락 실측
- [ ] 편집 가능(네이티브 객체), 수식/숫자 변조 없음
- [ ] 보고서 4블록: **PASS/재작업** · 유지한 사실+출처 · 실패 항목 · 렌더 상태

| 형식 | 만족해야 할 것 | 통과 불가 |
| --- | --- | --- |
| **PPTX** | 슬라이드마다 메시지 1개(액션 타이틀, 제목=결론), 도형·차트 원본 편집 가능 | 겹침 1건 · 글자 잘림 · 도형 깨짐 → 수정 |
| **DOCX** | 제목 스타일(굵게 아님)·목차·각주 정상, 표·페이지 나눔 정상, 글꼴 대체 확인 | 표 분할 오류 · 목차 끊김 → 수정 |
| **XLSX** | 시트 분리(입력/계산/결과/대시보드), 결과는 실제 수식 연결, 참조 유효 | 수식 오류 · 캐시 불일치 → 재계산 |
| **PDF** | 페이지 누락 0, 폰트 포함, 표·그림 페이지 분리·여백·인쇄 대비, 텍스트 추출 대조 | 페이지 누락/렌더 깨짐 → 재생성 |
| **HWPX** | 구조 검사 통과, 한글 줄바꿈·표 너비·결재란·쪽 번호 확인, 엔진 없으면 `unavailable` 명시 | 구조 검사 미통과 → 보류 |

## 파싱 정밀도 (읽기·추출 — 파일을 '데이터'로 쓸 때 게이트; kordoc 실측 장점 기준 자체 작성)

- [ ] **구조 보존**: 표 추출 시 병합 셀(rowspan/colspan)·행/열 정렬 보존 확인 — 병합 깨짐 = FAIL, 보존 불가 도구면 `unavailable` 명시
- [ ] **소비자별 출력 분리**: 사람용(Markdown)·구조 데이터(blocks/IR)·검색용(제목 경로 붙인 청크 + 독립 표 청크) — 하나의 결과라고 단정하지 않기
- [ ] **부분 성공 보고**: 추출 실패 항목은 누락으로 감추지 않고 **건너뛴 항목 + 사유**로 보고
- [ ] **회복적 파싱**: 깨진 구조(XML 등)도 부분 추출 + 손상 항목 명시(0개여야 한다고 주장하지 않기)
- [ ] **스캔/이미지 계층 표기**: OCR·이미지 근거 텍스트는 실측/추정 구분 표기(추정을 실측으로 서술 금지)
- [ ] **인용 경계**: 파싱한 원문 문구를 사용할 때 출처 + 변환(추출) 표기 — 원본 재생산 아님을 명시

- [ ] **근거 신뢰 라벨**: 각 주장에 신뢰도 구분(확인 Confirmed / 추정 Likely / 가설 Hypothesis) — 라벨 없는 주장은 '미검증' — 형식 무관 동일 라벨 공유
- [ ] **자산 출처·credit 라벨**: 포함 이미지·폰트·자산 출처 표기(원본 유지 시 credit 유지, 계약 바뀌면 재판정 — LICENSE/NOTICE 미판독 = 미판정)
- [ ] **원문 미복사**: 라이선스 예외·미판정 소스는 복사 금지 — 아이디어만 취해 자체 구성(제로 허용 사다리 §7)

## 실측 원칙

- 검증 도구 부재 = `unavailable` 보고(무시·숨김 금지) — 빌더 자기 승인 금지, 독립 비판 통과 후 보고.
- 게이트가 검수 자체는 아님: 통과 보고서에는 **확인한 것과 확인하지 못한 것**이 함께 적혀야 한다.
