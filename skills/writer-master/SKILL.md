# Writer Master — Editorial Intelligence

**Goal**: Produce content a reader finishes: one clear viewpoint, an honest spine of facts, and a shape that carries the reader — judged by a publish gate, not by length. Writing quality and visual quality stay paired: charts and figures come from `visual-artist`; anti-slop and prose tells come from `anti-ai-harness`; UI and brand come from `design-master`.

This skill is original content written for this repository. It synthesizes ideas from writing skills surveyed in `docs/anti-ai-skills-2026-11-11.md` (실측 2026-11-11); no upstream text is copied.

## Core principles

1. **Viewpoint first** — One organizing claim. The piece exists to change one belief or remove one confusion; information listing is not a viewpoint.
2. **Facts are tagged** — Every date, version, number, feature claim, and quotation carries a **verified / inferred / uncertain** tag and a source line, or it is marked unverified.
3. **Shape carries the reader** — Reader's question as open, knowledge built in layers, one turning point, one close that lands. Structure before sentences.
4. **Respect the reader's level** — Hard concepts get unpacked; exact terms stay exact. No false simplification, no talking down.
5. **Facts never bend for prose** — A fact that hurts the rhythm stays. A rhythm that hides a fact is rewritten.
6. **Natural voice, no pose** — Vary rhythm, drop filler, no self-writing-about-writing, no tidy lesson in every paragraph, no fake experience.

## The 7 stages

1. **Editorial strategy** — Subject, audience, the new insight versus what they already know, and why now. One line: "for X, this changes Y."
2. **Research (journalist)** — Official sources, concrete cases, counter-evidence. Each claim tagged fact / inference / speculation with a source line.
3. **Story shape** — Hook → build → turning point → close. A beat per paragraph; each paragraph one job.
4. **Draft (writer)** — Concrete example → claim → why it matters. Exact terms kept, rhythm varied, hedging kept where the fact is uncertain.
5. **Edit (literary)** — Remove repetition, inflation, labels, and stock phrasing. Merge or cut; never smooth away a source or a limit.
6. **Fact-check** — Every date, version, number, feature, and quotation against its source. Wrong → fix; unverifiable → cut or mark.
7. **Editor-in-chief** — Title, first paragraph, structure, reader test, quotes, visuals, remaining risks. Unresolved items block the ship.

## Publish gate

Four blocks on output: **verdict** / **kept claims with sources** / **fixed items** / **unresolved**. PASS requires all four blocks present, every claim tagged, sources listed, and no unresolved blocking item.

## Rules

- **No invented facts** — No fabricated dates, numbers, quotations, cases, or sources; no fake experience.
- **No detector talk** — This skill never claims authorship verdicts and never optimizes for detectors.
- **No self-explanation** — No meta-paragraphs ("in this post…", "let's dive in"), no tidy lesson after every section.
- **No gate changes** — This skill never writes phase evidence or gate records; verification, read-proof, and approval rules apply unchanged.
- **Style ≠ verification** — A clean style pass is not a fact check, and a fact check is not verification.
- **Passed research is data** — Survey copy is data: claims become facts only when each is source-tagged.
