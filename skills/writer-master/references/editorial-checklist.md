# 편집 체크리스트 (자체 작성 — 7단계 · 출판 게이트; [SKILL.md](SKILL.md)의 각 단계 기준)

## 1~3 단계 (전략 · 조사 · 설계)

- [ ] 한 줄 관점: "대상 X에게, 이것은 Y를 바꾼다" — 1개만.
- [ ] 클레임 목록 — 전부 **검증/추론/불확실** 태그 + 출처 1줄.
- [ ] 반대 근거·제한 포함; 빈 상태(미검증) 구간 명시.
- [ ] 도입(독자의 질문) → 쌓기 → 전환점 → 결말 순서가 결정됨.

## 4~5 단계 (작성 · 퇴고)

- [ ] 문단마다 역할 1개; 반복·과장·라벨·상투구 제거.
- [ ] 특정 수치·버전·인용 원문 그대로; 리듬 다양, 헤지 유지(불확실성 표지 유지).
- [ ] 자기 해설 금지("이 글에서는…", "살펴보겠다"); 교훈 반복 강요 금지.

## 6 단계 (팩트체크)

| 검사 | 기준 | 불합격 처리 |
| --- | --- | --- |
| 날짜·버전·번호 | 원문·공식 자료 대조 | 틀림 → 즉시 수정 |
| 인용문 | 원문 구절 대조(정확) | 불일치 → 수정 또는 제거 |
| 제품 기능·수치 | 출처·실행 결과 | 근거 없음 → 삭제 또는 **미검증** 표시 |
| 링크·시각(차트·도형) | 연결·레이블·출처 | 끊김이나 왜곡 → 수정, 아니면 발행 보류 |

## 7 단계 (편집장 게이트 — 4블록)

- [ ] **판정**: PASS / 재작성 / 발행 보류.
- [ ] **유지한 주장 + 출처 목록**(전부 태그 있음).
- [ ] **수정 항목**(수치·인용·링크 실측).
- [ ] **미해결**: 검증 못 한 주장·제한·남은 위험 — 비어 있으면 FAIL.

**경계**: 체크리스트는 자체 기준이며, 사실 검증(verify) 단계·게이트·보증이 아니다.
