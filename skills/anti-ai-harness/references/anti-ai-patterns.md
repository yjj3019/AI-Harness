# Anti-AI 패턴 체크리스트 (자체 작성 — [docs/anti-ai-skills-2026-11-11.md](../anti-ai-skills-2026-11-11.md)의 실측 요약 기반 아이디어만 취함, 원문 미복사)

검수는 목적과 독자를 먼저 읽고, 문체는 근거 유지 수정만 한다. 각 항목에 **근거**(인용·링크·로그) 또는 **삭제** 중 하나가 붙어야 한다. 저자 판정·탐지 예측 문구는 쓰지 않는다.

## A. UI (레이아웃 · 색 · 컴포넌트 · 모션)

- [ ] 그라디언트·보라색 그라디언트가 목적 문장 없이 반복 → 제거 또는 근거.
- [ ] 카드 3칸 반복 · 동일 카드가 무관 화면에 반복 → 축소 또는 구체 예시.
- [ ] 히어로의 가짜 성능 수치(허구 메트릭) → 실제 값 또는 제거.
- [ ] 이모지 장식 · 장식적 굵음/꾸밈 → 제거.
- [ ] 폼·대시보드 상태(빈 · 로딩 · 오류 · 오프라인) 누락 → 상태 추가 또는 "미검수" 표기.

## B. 문체 (사실 보존 문장)

- [ ] "그냥 X가 아니라 Y" · "핵심은 ~" 류 기법 문구 → 목적 문장 + 근거.
- [ ] 무의미 강조("~을 위한" · "이제 시작" 류) → 평서문으로.
- [ ] 콜론 나열 · 반복 서두 · 반복 마무리 → 병합·분리·문장 수 축소.
- [ ] 대시 만능 · 글머리 꾸밈(굵게·이모지) → 문장 구조 변경 또는 삭제.
- [ ] 헤지 겹침("~일 수도 있으며" 반복) → 근거 있는 것만 유지.

## C. 코드 (주석 · 변환)

- [ ] 주석이 코드를 그대로 되풀이 → 제거, "왜"만 남김.
- [ ] 장식 배너 · 자기 칭찬 주석 → 제거.
- [ ] 주석의 숫자·비율·인용 → 출처 없으면 삭제 또는 출처 명시.

## D. 문서 · 보고

- [ ] 첫 문장이 제목을 되풀이 → 제목이 하게 하고 문장은 본문 일부로.
- [ ] 겹치는 강조 단어 스택 → 근거 또는 삭제.

## E. 근거 게이트 (검수 종료 시)

- [ ] 4블록 기재: **변경** / **유지**(보존한 사실) / **근거**(출처·로그) / **미검수**(확인 못 한 구간).
- [ ] 블록이 비어 있으면 FAIL.
- [ ] 검수 완료 ≠ 증거 검증(verify) 완료 — 두 역할을 분리해 기록.

**경계**: 이 리스트는 README 실측 기반의 자체 패턴 요약이며 아이디어만 반영한 자체 작성이다. 실행 보증·무결점이 아니며 저자 판정·탐지 우회를 목적으로 하지 않는다.
