# Skill Eval Checklist

## Structure
- name matches directory
- description has concrete “Use when” triggers
- body is reasonably short; references used for depth

## Trigger
- 5+ positive example phrases listed
- 3+ negative example phrases listed
- description covers the positive cases

## Outcome (optional)
- Small task defined
- With-skill run recorded
- Without-skill run recorded
- Delta noted (helped / neutral / hurt)

## Decision
- Keep / revise / drop
- Residual risks listed
